# Compact portfolio review

September 17, 2026. User-approved six-section revision, published through the existing GitHub/Vercel connection.

## Result

The previous chapter sequence would make the portfolio too long. The new order is Hero → Ahmad.AI → DevOps/Infrastructure → Agentic AI → Projects → Contact/footer. RAG is included in agent capabilities; CloudOps appears in the project selector. The hero portrait, likeness, palette and existing pointer response are preserved.

One canvas and the original portrait source carry the narrative. Portrait particles disperse, gather into an abstract bot symbol beside chat, become an infrastructure topology, reform into the Reason / Act / Verify network, and morph into the selected project. Contact returns them to quiet ambience. Reverse scrolling restores earlier forms and the portrait. Project selection interpolates the same destination buffer; pausing queues that change until motion resumes. No generic face or extra portrait geometry is introduced.

Desktop follows the approved alternating composition. Mobile recomposes the pairs and places project controls before the figure/details. Ruled capability lists replace long card rows. The main measures approximately 4,855px at 1440×960, without long sticky spans. Short desktops, tablet layouts, phone layouts and 320px/200%-text controls were inspected and refined.

## Ahmad.AI

The chat and server endpoint are implemented with Groq primary and Gemini fallback. Keys remain server-side. Without configured providers, answers visibly identify direct public-profile references. Unsupported facts are admitted; CloudOps scope remains planned. Provider failures return labeled profile answers. Chat has retryable errors, bounded input/history, timeouts and process-local rate/concurrency limits. No persistent conversation storage, actions, browsing or pretend execution.

Provider failover and invalid-source rejection are tested with mocked responses. A supplied local Gemini key was moved from the tracked example into ignored local configuration; example keys remain blank. Automatic approval review initially rejected a live Gemini test because setup had been deferred. The user then explicitly approved the local test and reported adding both keys in Vercel. That one test returned HTTP 200 with the labeled provider-unavailable profile fallback; a Gemini-generated answer was not confirmed. Detailed provider errors are intentionally not exposed to visitors. Provider configuration/answer quality remains to be verified beyond key detection. Allowlisted source IDs constrain links, not the semantic correctness of every generated statement; process-local limits are not a distributed spending guarantee.

## Validation

Lint, typecheck and production build pass. All 29 Playwright checks passed in 30.3 seconds, with server keys explicitly blank for deterministic profile-reference browser tests. The suite checks six widths, keyboard controls, profile-reference answers, API validation, mocked provider failover, retryable errors, one-canvas morphing/reversal, project selection while paused, reduced motion, live preference changes, WebGL initialization/context loss, no JavaScript and enlarged text.

Quiet Chromium 153.0.8010.12 observation at 1440×960: 179 animation-frame intervals, median 16.7ms and p95 16.8ms after adaptation to economy quality; renderer averaging window 17.6ms. This environment uses SwiftShader software WebGL. It measures browser scheduling rather than native GPU presentation or universal 60fps. Physical-phone/Safari profiling and live model-answer evaluation remain outstanding. [Raw performance observation](review/compact-performance.json).
